# Dataset license, attribution, and scenario separation

The uploaded `concrete.csv` has the nine columns and 1,030 records of the UCI **Concrete Compressive Strength** dataset by I-Cheng Yeh.

> Yeh, I. (1998). *Concrete Compressive Strength* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5PK67

Source: https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength

The UCI listing specifies **Creative Commons Attribution 4.0 International (CC BY 4.0)**, https://creativecommons.org/licenses/by/4.0/ . Attribution to the dataset creator and repository is required. The original features have been renamed to the uploaded CSV labels (e.g. `coarseagg`); aside from using the supplied file, no original dataset rows were synthesized. The generated 28-day BOM is an analytical adaptation of observed mixes.

The model-created scenario tables (inventory, production orders, suppliers, orders and cost assumptions) are synthetic and are not included in the UCI dataset. Project code and documentation are newly created examples.

No actual field-testing certification, site-specific suitability, structural design endorsement, price quote, or real purchase order is provided.
